# Prompt 01 — Architecture Review

Прочитай `CLAUDE.md`, все документы в `docs/`, `data/` и `references/README.md`.

Не начинай production-разработку.

## Задача

1. Проверить согласованность документации.
2. Найти противоречия и неопределённые решения.
3. Предложить окончательную модель главной.
4. Уточнить state machine.
5. Предложить React architecture.
6. Определить минимальный набор client components.
7. Разделить HTML, SVG, CSS и WebGL.
8. Предложить URL model.
9. Составить plan low-fidelity prototype.
10. Создать decision log.

## Создать

- `docs/17-decision-log.md`
- `docs/18-component-architecture.md`
- `docs/19-prototype-plan.md`

## Ограничения

- не создавать финальный дизайн;
- не генерировать 3D;
- не начинать весь сайт;
- не менять коммерческую идею без обоснования;
- не помещать interface в Canvas;
- не игнорировать mobile и reduced motion;
- не выдумывать бизнес-данные.

В финале перечисли решения, противоречия, открытые вопросы, scope прототипа и изменённые файлы. Затем остановись.
