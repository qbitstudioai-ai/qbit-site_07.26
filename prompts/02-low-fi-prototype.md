# Prompt 02 — Low-Fidelity Prototype

Используй утверждённые документы и decision log.

## Цель

Создать функциональный low-fidelity prototype без финальной графики.

## В scope

- Next.js + TypeScript;
- базовые стили;
- overview как схема;
- пять HTML/SVG zones;
- hover/focus/touch;
- state machine;
- URL state;
- desktop 10/90;
- switch/close/Escape;
- reduced motion;
- mobile touch flow;
- static fallback;
- Playwright tests.

## Не в scope

Финальные изображения, сложное 3D, персонажи, backend, CRM, рабочая форма, калькулятор и все SEO-страницы.

## Процесс

1. Сначала plan files/dependencies.
2. Инициализировать только необходимое.
3. Реализовывать малыми шагами.
4. После каждого шага запускать checks.
5. Проверить browser, console, keyboard, mobile и reduced motion.

## Готовность

Пять отделов доступны мышью, клавиатурой и касанием; 10/90 и URL работают; Escape возвращает overview; visual layer заменяем; tests/build проходят.

В финале дай команды запуска, результаты проверок, ограничения и следующий шаг.
