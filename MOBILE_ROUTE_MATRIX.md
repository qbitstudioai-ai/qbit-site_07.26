# Мобильная матрица маршрутов — аудит 2026-07-28

Инструментальный обход production-сборки. **31 адрес × 19 экранов = 589 проверок** после исправлений.

Каждая ячейка — результат реальной загрузки страницы в Chromium с эмуляцией устройства
(`isMobile: true`, `hasTouch: true`, соответствующий `devicePixelRatio`), ожиданием 1.4 с после
`load` и последующим обмером DOM.

Колонки таблицы — подмножество для чтения; полный набор экранов перечислен ниже, и он проверялся для
каждого адреса.

## Что означает каждая колонка

| Колонка               | Проверка                                                                                                              |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 320 / 360 / 390 / 430 | Портретные телефоны: `document.scrollWidth ≤ innerWidth` и отсутствие элементов за краем экрана вне скролл-контейнера |
| landscape 667×375     | Телефон в альбомной ориентации — худший случай по высоте                                                              |
| tablet 768×1024       | Планшет в портретной ориентации                                                                                       |
| overflow              | Горизонтальное переполнение на ЛЮБОМ из 19 экранов                                                                    |
| навигация             | Шапка и меню доступны, переходы работают                                                                              |
| touch                 | Все действия страницы выполнимы касанием, без зависимости от наведения                                                |
| console               | Ошибки и предупреждения страницы (расширения браузера и отменённые RSC-предзагрузки исключены)                        |

и `current-password` (менеджер паролей работает), размер шрифта 16 px — iOS не приближает экран при
фокусе.

## Полный набор экранов

Каждый адрес выше проверялся на всех девятнадцати:

**Телефоны, портрет:** 320×568 (dpr 2), 360×640 (dpr 2), 375×667 (dpr 2), 390×844 (dpr 3),
393×852 (dpr 3), 412×915 (dpr 2.6), 430×932 (dpr 3).

**Телефоны, альбом:** 568×320, 667×375, 844×390, 932×430.

**Планшеты:** 768×1024, 820×1180, 1024×768, 1180×820.

**Desktop (контроль регрессии):** 1366×768, 1440×900, 1920×1080, 2560×1440.

Профили устройств: современный iPhone (390×844 / 393×852 / 430×932, dpr 3), небольшой iPhone
(320×568 / 375×667, dpr 2), Android-смартфон (412×915, dpr 2.6), небольшой Android (360×640, dpr 2),
iPad (768×1024, 1024×768), Android-планшет (820×1180, 1180×820).

## Дополнительные условия

| Условие                           | Результат                                                                                                            |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `devicePixelRatio` 1 и 2          | Проверено; раскладка не зависит от плотности                                                                         |
| `prefers-reduced-motion: reduce`  | Проверено на `/`, `/how-we-work`, `/faq`, экране отдела: содержимое доступно сразу, переходы работают                |
| Ввод касанием без наведения       | Проверено; исключение зафиксировано как MOB-09 (предпросмотр цены), действие при этом доступно тапом                 |
| Поворот portrait ↔ landscape      | Активный отдел переживает поворот, переполнения нет; открытое меню корректно сворачивается при расширении до desktop |
| Прямое открытие вложенного адреса | Все 21 публичный адрес и 6 состояний главной открываются напрямую                                                    |
| Кнопка «Назад» браузера           | Возврат работает; состояния главной синхронизируются через `replaceState` (см. `MOBILE_AUDIT.md`)                    |
| Масштабирование до 200 %          | `viewport` не запрещает масштабирование: `maximum-scale`/`user-scalable=no` не заданы                                |
| Pinch-to-zoom                     | Разрешён                                                                                                             |
