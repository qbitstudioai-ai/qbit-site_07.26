# Office Map

## Предварительное расположение

```text
┌──────────────────────────────────────────────────────────────┐
│                  ДИРЕКЦИЯ / УПРАВЛЕНИЕ                       │
│                                                              │
│  ТЕХНИЧЕСКАЯ ПОДДЕРЖКА      ОБЩАЯ ЗОНА             HR        │
│                                                              │
│       ПРОДАЖИ                            ЛОГИСТИКА            │
└──────────────────────────────────────────────────────────────┘
```

## Логика

- Дирекция находится выше и принимает агрегированные потоки.
- Поддержка — крупная операционная зона слева.
- Продажи — заметная нижняя левая зона.
- HR связан с переговорными и зоной ожидания.
- Логистика — операционная правая нижняя зона с картами и статусами.
- Центр объединяет офис и резервирует место для hero.

## Каждая зона имеет

- стабильный `departmentId`;
- HTML-кнопку;
- SVG/DOM-контур;
- hover/focus/selected;
- доступную подпись;
- короткое описание проблемы.

## Камера

Нет свободного полёта. Только:

- слабый параллакс;
- контролируемое приближение;
- переход в 10/90;
- короткое переключение;
- однозначный возврат.

## Режим 10/90

Левая панель 10–14%:

- возврат;
- пять миниатюр;
- активное состояние;
- клавиатурная навигация.

Основная область:

- сцена;
- заголовок;
- симптомы;
- до/после;
- результат;
- CTA.

## Mobile

Не уменьшенная карта, а отдельный touch-путь: обзор, карусель/пейджинг карточек отделов (одна
карточка видна за раз, переключение кнопками «предыдущий»/«следующий»), полноэкранная карточка
открытого отдела с прямым переключением между отделами, явная кнопка назад и CTA.
