# Implementation Plan

## Этап 0 — репозиторий

Next.js, TypeScript, lint, formatter, tests, Playwright, CI, tokens и структура каталогов.

## Этап 1 — low-fidelity

Overview, пять HTML/SVG hotspots, hover/focus/touch, state machine, URL, 10/90, switch, close, keyboard, reduced motion, mobile и fallback.

## Этап 2 — art direction

Карта офиса, safe areas, typography, palette tokens, lighting, department differentiation и responsive frames.

## Этап 3 — sales pilot

Полная сцена, до/после, copy, CTA, analytics, calculator prototype, performance и accessibility.

## Этапы 4–7

Поддержка, дирекция, HR и логистика на общем шаблоне.

## Этап 8 — диагностика

Роль, сфера, отдел, проблемы, результат, lead capture, consent, analytics и fallback.

## Этап 9 — внутренние страницы

Solutions, department pages, audit, cases, blog, contacts.

## Этап 10 — hardening

Performance, accessibility, visual regression, fallback, cross-browser, analytics, security, SEO и production build.

## Правило

Каждый этап: план → scope → criteria → implementation → checks → browser review → report → approval.
