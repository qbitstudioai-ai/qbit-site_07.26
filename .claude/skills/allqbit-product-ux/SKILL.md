# Allqbit Product UX

Прочитать `docs/00-product-brief.md`, `01-audience-positioning.md`, `03-office-map.md`, `05-homepage-state-machine.md`, `14-acceptance-criteria.md`.

Проверить:

1. Обещание понятно за 3–5 секунд?
2. Можно отправить заявку без исследования офиса?
3. Ясна интерактивность?
4. Отделы отличаются по проблеме?
5. Нет тупиков?
6. Сохраняется контекст 10/90?
7. Работают URL/history?
8. Есть mobile touch?
9. Есть reduced motion?
10. Возвращается focus?

Выход: сильные решения, проблемы по приоритету, изменения и вопросы владельцу. Не переписывать код, если запрос — аудит.
