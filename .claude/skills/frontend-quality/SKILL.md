# Frontend Quality

Проверить server/client boundaries, types, duplication, data-driven departments, cleanup, error boundaries, loading, code splitting, images, accessibility, secrets, tests и build.

После появления scripts выполнить эквиваленты:

```bash
npm run format:check
npm run lint
npm run typecheck
npm run test
npm run build
```

Ревью: Blocker, Critical, Major, Minor, Suggestion. Компиляция не означает готовность.
